# Skelo Flutter example

Run `flutter pub get` and `flutter run -d chrome` in this folder. The requests are simulated. Use the buttons to load, refresh, fail and retry activity while keeping the profile input mounted.

Run `flutter test --concurrency=2` for the example workflow, or `flutter build web` to compile it without opening a browser. To add phone targets, run `flutter create --platforms=ios,android .` before running on a device.
