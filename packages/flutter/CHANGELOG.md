## 0.2.0-preview.1

First public Flutter preview. Includes independent loading regions, retained
content during refresh, scoped errors and retries, template skeletons and
registered geometry comparisons. The pure Dart core uses the same snapshot
format as the JavaScript package.

Widget tests, web compilation and iOS/Android simulator workflows have passed.
Hardware devices and screen readers remain untested. Tests and their shared
fixtures are included so the archive works independently of the repository.
